# 🤖 Три робота

**Логические загадки: честный, лжец и случайный. Найдите шестерёнку и вычислите, кто есть кто.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/three-robots/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Загадки генерируются заново каждый раз
- Решатель перебирает все миры и гарантирует единственный ответ
- Утверждения с импликациями и ссылками на чужие реплики
- Разбор после ответа: какая фраза правдива, какая ложна
- Подсказки, батарейки-жизни и рекорд уровня

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/three-robots.git
cd three-robots
python3 -m http.server 8000
```
